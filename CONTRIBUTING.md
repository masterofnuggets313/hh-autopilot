# Как помочь проекту

## Что полезно

- Новые признаки холодного поиска и ГПХ в `hhjob/filters.py`, с примером текста вакансии.
- Улучшение парсера брендированных описаний.
- Тесты на реальных, но обезличенных текстах вакансий.
- Правки README, если что-то непонятно с первого чтения.

## Что не принимается

- Обход капчи и любые приемы против защиты hh.
- Массовая рассылка откликов без писем.
- Код, который выдумывает данные о человеке.
- Личные данные в тестах и примерах.

## Процесс

1. Issue с описанием проблемы и примером.
2. Ветка, изменение, тест.
3. `python -m pytest` должен проходить.
4. Pull request с одной понятной темой.

## Стиль кода

- Python 3.12, типизация по возможности.
- Никаких зависимостей сверх `hh-applicant-tool` и `requests`, кроме опционального `openpyxl`.
- Все внешние вызовы обернуты в try, потому что API меняется.
