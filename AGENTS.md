# Правила для агента

Ты работаешь с репозиторием hh-autopilot: помогаешь человеку искать работу на hh.ru.
Читай этот файл перед первым действием и следуй ему, если пользователь не сказал иначе.

## Что можно без подтверждения

- читать `config.toml`, `profile.toml`, `data/*.json`, `.state/sent.json`;
- запускать `hhjob doctor`, `hhjob search`, `hhjob describe`, `hhjob letters`;
- запускать `hhjob apply --dry`;
- запускать `hhjob chats` без `--reply`;
- запускать `hhjob report`;
- запускать `hhjob lint` по любым текстам;
- править шаблоны и код, если задача про это.

## Что только с явным подтверждением

- `hhjob apply` без `--dry`, то есть реальная отправка откликов;
- `hhjob chats --reply`, то есть сообщение работодателю;
- любые правки `profile.toml`, которые меняют факты о человеке;
- `git push` и создание публичного репозитория;
- удаление `data/` и `.state/`.

Перед реальной отправкой всегда показывай: сколько откликов, в какие компании, какой текст уйдет, с какого резюме. Одна строка на вакансию, без простыней.

## Жесткие запреты

1. **Не выдумывать факты.** Опыт, цифры, компании, сроки берутся только из `profile.toml` и из того, что человек сказал сам. Если данных нет, оставь пробел и спроси.
2. **Не обходить капчу.** Капча это стоп. Скажи об этом и предложи снизить темп или подождать.
3. **Не повышать лимиты молча.** `per_day` выше 40 это почти гарантированная капча.
4. **Не отправлять письмо с плейсхолдером.** Если `hhjob letters` вернул проблемы, отправка запрещена.
5. **Не публиковать личные данные.** Перед любым `git push` проверь, что в индексе нет `.env`, `config.toml`, `profile.toml`, `data/`, `.state/`, скриншотов переписки и id резюме.
6. **Не отвечать работодателю за человека в спорных случаях.** Вопрос про опыт, деньги, гражданство, здоровье: сначала спроси человека, потом отправляй.

## Как проверять результат

После отправки откликов не верь отчету скрипта. Проверь по API:

1. переговоры по этим вакансиям существуют и в статусе `response`;
2. в каждом есть сообщение от соискателя;
3. текст сообщения совпадает с тем, что было в `data/letters.json`.

Если расходится, скажи прямо, а не подводи итог «все хорошо».

## Стиль текстов

Перед отправкой любого письма прогоняй `hhjob lint`. Требования в `prompts/style-ru.md`.
Коротко: без длинных тире, без буквы ё, без многоточий, числа цифрами, деньги словом «руб.»,
никаких оборотов «не просто X, а Y».

## Порядок работы

1. `hhjob doctor`, чтобы понять состояние.
2. `hhjob search`, затем `hhjob describe`, затем `hhjob letters`.
3. Показать человеку список и письма. Дождаться решения.
4. `hhjob apply --dry`, затем отправка.
5. Проверка по API, запись в журнал, короткий отчет человеку.

Подробный сценарий в `prompts/agent-workflow.md`.
