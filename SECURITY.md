# Безопасность и данные

## Что хранится локально

| Файл | Что внутри | В git |
|---|---|---|
| `.env` | пути, прокси | нет |
| `config.toml` | id резюме, запросы, лимиты | нет |
| `profile.toml` | ваши факты для писем | нет |
| `data/` | собранные вакансии, письма, отчеты | нет |
| `.state/sent.json` | журнал отправленного | нет |
| каталог `hh-applicant-tool` | токен OAuth | нет, лежит вне репозитория |

В репозитории только код, примеры конфигов и шаблоны.

## Токен

Токен hh выдает `hh-applicant-tool auth`. Он лежит в каталоге, который задан
переменной `HH_CONFIG_DIR`. Не копируйте этот каталог в проект и не публикуйте.

Если токен утек: отзовите доступ в настройках hh и авторизуйтесь заново.

## Капча и лимиты

При частых откликах hh включает капчу. Это защита площадки. Проект останавливается
и не пытается ее обойти.

Практические ориентиры:

- 8 или 10 откликов за один запуск;
- не больше 40 в сутки;
- пауза 4 секунды между запросами;
- после появления капчи остановиться на несколько часов, а не подбирать слова.

## Публикация форка

Перед `git push` проверьте:

```bash
git status --short
git grep -n -i -E "resume_id = \"[0-9a-f]{20,}|@gmail|@mail|\\+7 ?[0-9]{3}"
```

Если что-то нашлось, уберите из индекса и добавьте в `.gitignore`.

## Что сообщать в issues

Не прикладывайте: скриншоты переписки, id резюме, токены, телефоны, названия компаний,
где вы сейчас в процессе. Для баг-репорта достаточно текста ошибки и версии Python.
