# Сценарий работы агента

Пошаговый цикл. Каждый шаг заканчивается проверяемым результатом, а не обещанием.

## Шаг 0. Состояние

```
hhjob doctor
```

Читаем: авторизация, видимые резюме, треки, блоки профиля. Если чего-то нет, говорим
человеку, что именно нужно заполнить, и не идем дальше.

## Шаг 1. Сбор

```
hhjob search --track <трек> --salary <планка>
```

Смотрим три числа: сколько собрано, сколько осталось после фильтров, сколько с оценкой
выше нуля. Если после фильтров меньше 10 вакансий, проблема в запросах: слишком узкие.
Предложи расширить, а не снижать планку по деньгам.

## Шаг 2. Отбор

```
hhjob describe --limit 12
```

Читаем описания. Отсеиваем по смыслу: несовпадение уровня, работа на телефоне, смены,
разъезды, странное оформление. Отдельно проверяем работодателя: доверенный ли, есть ли
аккредитация ИТ, сколько открытых вакансий, есть ли сайт.

Итог шага: список из 5 или 8 вакансий с одной строкой причины «почему берем».

## Шаг 3. Письма

```
hhjob letters
hhjob lint data/letters.json
```

Если письмо получилось пустым или общим, это сигнал, что в `profile.toml` мало фактов.
Скажи об этом человеку, предложи добавить 2 или 3 блока с цифрами. Не выдумывай сам.

## Шаг 4. Показ и решение

Таблица: компания, вакансия, деньги на руки, оформление, холодный поиск, чем цепляем.
Ниже письма целиком. Вопрос один: отправляем все или что-то убрать.

## Шаг 5. Отправка

```
hhjob apply --dry
hhjob apply --limit <N>
```

Перед этим убедись, что `per_day` не превышен: `.state/sent.json` помнит даты.

## Шаг 6. Проверка

Проверь по API, как описано в `AGENTS.md`. Посчитай: отправлено, пропущено, ошибки.
Если пришла капча, останови работу и скажи об этом.

## Шаг 7. Разбор ответов

```
hhjob chats
hhjob report
```

По чатам: боты принимают короткий ответ вроде «Да» или «Нет». Длинный текст бот
не разбирает и повторяет вопрос. Если вопрос требует развернутого ответа, сначала
согласуй текст с человеком.

## Шаг 8. Итог

Три блока, коротко:

1. что сделано (цифры);
2. что ждет человека (ответы, анкеты, тестовые);
3. что стало тупиком и почему.

Без воды. Человек читает это вместо того, чтобы держать все в голове.
